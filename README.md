# WalletPrep

WalletPrep is a Nimiq/EVM wallet transaction ledger organizer for bookkeeping and tax-prep record organization.

It helps users collect, normalize, review, annotate, categorize, and export wallet transaction records. WalletPrep does **not** calculate taxes, determine tax liability, or provide tax, legal, or accounting advice.

## Security

Seed phrases, private keys, secrets, credentials, and signing material must never be committed to this repository.
